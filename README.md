
# ✍️ AI Writing Assistant

An AI-powered writing application built using Python and Streamlit that helps users generate high-quality content for different writing tasks.

## 🚀 Features

- Blog Writing
- Email Drafting
- Code Explanation
- Social Media Post Generation
- Multiple AI provider support
- Adjustable temperature control
- Customizable output length
- Markdown and text formatting

## 🛠️ Technologies Used

- Python
- Streamlit
- OpenAI API
- Google Gemini API
- HTML and CSS
- Prompt Engineering

## ⚙️ Installation and Setup

### 1. Clone the repository

git clone YOUR_GITHUB_REPOSITORY_URL

### 2. Navigate to the project folder

cd AI_Writing_Assistant

### 3. Create a virtual environment

python -m venv .venv

### 4. Activate the environment

Windows:

.venv\Scripts\activate

### 5. Install dependencies

pip install -r requirements.txt

### 6. Configure API keys

Create a `.env` file and add your API keys.

Never upload your API keys to GitHub.

### 7. Run the application

streamlit run app.py

To develop an intelligent writing assistant that simplifies content creation through generative AI and customizable prompt templates.
